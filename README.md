# Новостройки Ташкента

Сайт собирает **реальные объявления о продаже** квартир в новостройках и новых домов / коттеджей / таунхаусов в Ташкенте и Ташкентской области с **OLX.uz** и **Uybor.uz**, показывает их с фильтрами и даёт **ИИ-оценку объекта и застройщика** (Claude с поиском в интернете).

## Как устроено

```
public/index.html        сайт (статический файл)
api/search.js            фильтрация и поиск — на сервере, браузер получает только страницу результатов
api/listing.js           полная карточка + сравнение цены с рынком
api/assess.js            ИИ-оценка дома и застройщика (Claude + web search)
api/refresh.js           статус данных / запуск сбора через GitHub Actions
lib/                     общий код функций
scraper/collect.mjs      сборщик объявлений (~25 минут)
.github/workflows/       ежедневный запуск сборщика
data/listings.json.gz    снимок данных (запасной вариант, если Blob не подключён)
scripts/dev-server.mjs   локальный сервер для разработки (на Vercel не используется)
```

Сбор длится ~25 минут — дольше лимита функций Vercel, поэтому он работает в **GitHub Actions** раз в сутки и загружает результат в **Vercel Blob**. Сайт подхватывает новые данные сам, без передеплоя.

## Деплой на Vercel

1. **Загрузите проект на GitHub** (новый репозиторий, ветка `main`).
2. **Vercel → Add New → Project →** выберите репозиторий. Framework Preset: **Other**, остальное по умолчанию (настройки уже в `vercel.json`). Deploy.
3. **Хранилище данных:** в проекте Vercel → **Storage → Create → Blob** → подключите к проекту. Переменная `BLOB_READ_WRITE_TOKEN` добавится сама.
4. **ИИ-оценка:** Vercel → Settings → Environment Variables → `ANTHROPIC_API_KEY` = ключ из https://console.anthropic.com.
5. **Ежедневный сбор:** GitHub → репозиторий → Settings → Secrets and variables → Actions → New secret `BLOB_READ_WRITE_TOKEN` (то же значение, что в Vercel). Затем Actions → «Сбор объявлений» → **Run workflow**, чтобы загрузить первые данные.
6. *(Необязательно)* чтобы работала кнопка **«↻ Обновить»** на сайте, добавьте в Vercel:
   - `GITHUB_REPO` = `ваш-логин/имя-репозитория`
   - `GITHUB_TOKEN` = fine-grained token (GitHub → Settings → Developer settings) с доступом к этому репозиторию и правом **Actions: Read and write**.
7. После изменения переменных сделайте **Redeploy**.

Пока Blob не подключён, сайт работает на снимке `data/listings.json.gz` из репозитория.

## Локальный запуск

Нужен Node.js 22.

```bash
npm install
npm start          # http://localhost:3000
npm run collect    # собрать свежие объявления локально (≈25 минут)
```

Для ИИ-оценки локально: `ANTHROPIC_API_KEY=... npm start`. Локально кнопка «Обновить» запускает сборщик прямо на компьютере.

## ИИ-оценка

В карточке объявления — кнопка **«🤖 ИИ-оценка дома и застройщика»**. Claude (`claude-opus-5-5`):
- определяет застройщика и ЖК, ищет в интернете сданные объекты, задержки сроков, отзывы, суды, новости;
- сравнивает цену за м² с медианой похожих объявлений (тот же район, тип, комнатность) из наших данных;
- выдаёт оценки 0–10 (общая, объект, застройщик), плюсы/минусы, тревожные сигналы, риски, вопросы продавцу и ссылки на источники.

Одна оценка занимает 30–90 секунд и стоит порядка нескольких центов (токены + веб-поиск). Результат кешируется на CDN Vercel на 7 дней, поэтому повторный просмотр бесплатный. Ограничение: 20 оценок в час с одного IP (`ASSESS_LIMIT_PER_HOUR`). Сравнение цены с рынком показывается в карточке всегда, без ИИ.

## Что попадает на сайт

| Источник | Что берём | Как определяем «новое» |
|---|---|---|
| OLX.uz — Квартиры, продажа | Тип жилья «Новостройки» и «От застройщика» | Поле OLX «Тип жилья» |
| OLX.uz — Дома, продажа | Дом, коттедж, таунхаус, дача | Поле «Год постройки/сдачи» ≥ 2023 |
| Uybor.uz — Квартиры, продажа | Только с отметкой «Новостройка» | Флаг сайта `isNewBuilding` |
| Uybor.uz — Дома, продажа | Только если в описании сказано, что дом новый | Слова «новый», «yangi», «сдача» и т.п. |

Отсекается: аренда, вторичный рынок, старые дома, квартиры дешевле 8 000 $ и дома дешевле 15 000 $ (обычно цена за м², участок или ошибка), участки земли, размещённые в разделе домов. Одинаковые объявления с двух сайтов помечаются как дубли и по умолчанию скрываются.

Настройки сборщика — объект `CONFIG` в начале `scraper/collect.mjs`.

## Ограничения

- Данные — снимок на момент сбора (обновляются раз в сутки). Цену и наличие проверяйте на сайте-источнике.
- ИИ-оценка может ошибаться; это не юридическая и не финансовая консультация.
- Если OLX или Uybor изменят своё API, сборщик нужно будет поправить.
